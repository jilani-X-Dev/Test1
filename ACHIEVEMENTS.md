# GitHub Profile Achievements — Practical Guide

This guide separates action-based achievements from program badges and historical or experimental badges. GitHub's achievement feature is in public preview, and exact thresholds or availability can change. Treat community-reported tier counts as guidance, not a contractual guarantee.

## Action-based achievements

| Achievement | Practical route | Notes |
| --- | --- | --- |
| Pull Shark | Get pull requests merged | Community-observed tiers: 2, 16, 128, 1,024 merged PRs. Prioritise useful changes and reviews. |
| Quickdraw | Close a newly opened issue or pull request within five minutes | Only do this for a genuine duplicate, invalid report, or already-resolved task. |
| YOLO | Merge your own pull request without a code review | Use only for safe changes when skipping review is genuinely appropriate. |
| Pair Extraordinaire | Co-author a commit in a merged pull request | Requires a real second contributor and accurate `Co-authored-by:` attribution. Community-observed tiers: 1, 10, 24, 48. |
| Galaxy Brain | Have answers accepted in Discussions on public repositories | Community-observed tiers: 2, 8, 16, 32 accepted answers. The asker or an eligible maintainer decides what is accepted; answer genuine questions. |
| Starstruck | Own a repository that earns stars from other GitHub users | Community-observed tiers: 16, 128, 512, 4,096 stars. Stars must be organic. |
| Public Sponsor | Publicly sponsor an eligible person or project through GitHub Sponsors | This can involve real money; never spend solely to chase a badge. |

## Program and profile badges

GitHub's official profile reference lists badges associated with participation in specific programs, including:

- Developer Program Member — register for the GitHub Developer Program and build an app using the GitHub API.
- Pro — have an active GitHub Pro subscription.
- Security Bug Bounty Hunter — qualify through GitHub's Security Bug Bounty program.
- GitHub Campus Expert — participate in the GitHub Campus Experts program.
- Security advisory credit — submit a security advisory that is accepted into the GitHub Advisory Database.

These are not substitutes for the action-based achievements above. Some require an application, subscription, security work, or program acceptance.

## Experimental, limited, or historical

- Heart On Your Sleeve and Open Sourcerer have had inconsistent community reports about testing or availability. Do not assume they can currently be unlocked.
- Arctic Code Vault Contributor and Mars 2020 Contributor are historical event achievements and cannot be earned through new work today.
- GitHub staff-only program achievements are not public activities a regular account can pursue.

## A genuine plan for Test1

1. Keep BadgeQuest accurate and useful; never mark a badge earned unless it appears on the profile.
2. Improve the project, add a demo, and share it with relevant developer communities to earn genuine stars.
3. Find a real collaborator for a meaningful change; include them as a co-author only when they actually contributed.
4. Answer real technical questions in Discussions on public repositories. Askers and maintainers control accepted-answer status.
5. Keep pull requests small, understandable, and valuable. Do not manufacture issues, stars, reviews, or commits.
